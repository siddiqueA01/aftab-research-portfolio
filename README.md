# Aftab Siddique, Ph.D. — Research Unfiltered (Version 3)

A cinematic, mobile-responsive research portfolio with a comprehensive scientific bibliography, a **2019–2026 curated media archive**, and dedicated **funding, awards, teaching, mentorship and invited speaking** sections. It uses the updated supplied portrait.

## What is included

- `index.html`, `styles.css`, `data.js`, `app.js`, `assets/*`: the complete Version 2 showcase (research case studies + 115 citation/abstract entries).
- `career.json` is the editable source of 22 reviewed-source media archive records and professional career sections; `career-data.js` is generated from it at build time. You only need to edit `career.json`.
- `generated/latest.json`: most recent automated search results. The file initially contains an empty placeholder and is **populated only when the update job runs**. Each run retains the prior discovery archive.
- `scripts/update_live.py`: **real automation**, fetching candidate news results from Google News RSS (up to a 90-day rolling search) and newly indexed publications from OpenAlex via ORCID `0000-0003-1427-4777`; it preserves prior data if a feed is temporarily unavailable.
- `.github/workflows/update-and-deploy.yml`: GitHub Actions schedule runs daily at ~08:27 UTC, can also be run manually, and deploys the finished static site to GitHub Pages.
- `bibliography.json` is the editable reference inventory; `bibliography.js` is generated at build time. `bibliography.csv` is an export of the original September 2026 bibliography and is not dynamically regenerated by the daily updater.

## Deploy and activate automatic updates (GitHub Pages)

1. Unzip the package and open the folder `Aftab_Siddique_Auto_Updating_Portfolio`.
2. Create a **public GitHub repository** (e.g., `aftab-research-portfolio`). Using **GitHub Desktop**, select **File → Add Local Repository**, choose the unzipped `Aftab_Siddique_Auto_Updating_Portfolio` folder, create the local Git repository if prompted, commit, and click **Publish repository** (keep the repository PUBLIC). Or use `git init; git add .; git commit -m "Publish portfolio"; git branch -M main; git remote add origin YOUR_REPO_URL; git push -u origin main`. Make sure the hidden `.github/workflows` folder is committed too.
3. In GitHub repository **Settings → Pages**, set **Build and deployment → Source = GitHub Actions**.
4. In **Actions**, open **Update & publish research portfolio** and choose **Run workflow** for the first build. When it finishes, GitHub Pages provides a shareable `https://username.github.io/aftab-research-portfolio/` URL.
5. Every day GitHub Actions reruns the collector and redeploys. GitHub may delay scheduled runs or disable scheduled workflows after inactivity in a public repository. Check the Actions tab if the displayed update timestamp stops changing.
6. Add the Pages URL to your CV/resume as **Interactive Academic Portfolio**. A custom domain may be configured in Pages settings.

**IMPORTANT:** Uploading the ZIP directly to Netlify Drop, opening the local HTML preview, or sharing the HTML file does **not** activate automatic updates. Automatic updates require the repository and workflow deployment above. GitHub Actions and external feed availability are subject to platform limitations.

## How automation behaves

- **Reviewed archive (22 source records):** 2019–2026 coverage and professional appearances curated as of 2026-10-14. It does **not** claim every name mention anywhere on the web was found. No confirmed non-scholarly news for 2019, 2020 or 2022 appeared in the investigated records. New candidate coverage goes to an explicitly labeled **automatically discovered / not reviewed** feed, not automatically into the verified archive.
- **Publications:** New OpenAlex entries match the author's **ORCID** and appear under a separate **newly indexed research** heading, where false positives, indexing errors or duplicates can be noticed before editorial promotion to the verified bibliography. Existing 115 records remain accessible offline.
- **Grants, awards, teaching, mentoring, presentations:** Curated manually from academic CV and documented updates; they **are not safely auto-verifiable** by OpenAlex or a news feed and do not auto-claim new grants or awards. Edit only `career.json`; `scripts/build_site.py` regenerates `career-data.js`.
- **Citation count:** October 2026 snapshot, not a live Google Scholar metric. There is no stable authorized public Google Scholar API used by this site.

## Editorial and privacy cautions

- Listed grant statuses are differentiated as `Awarded — CV documented`, `Funded`, or `Confirm award status`; grant proposals are labeled separately and are NOT awarded grants.
- 2026 National Goat Conference was **invited but canceled**, and is clearly excluded from delivered-talk counts.
- Reports that reprint university stories and authored professional outreach are categorized separately from independent media.
- Professional media (including WATT) can be paywalled. A linked source may change after the archive date.
- All publicly displayed personal information is professional/institutional only; no personal telephone number, residence, immigration information, or student identifying information included.

## Deployment status, domain, and verification

- **Not live until** uploaded to a GitHub repository and GitHub Pages deploys successfully. The ZIP alone does not create a site.
- On first run confirm that **Settings → Pages → Source** is **GitHub Actions**, then inspect the green check mark in **Actions** and click the Pages deployment URL.
- For a future domain such as `aftabsiddique.com`, you must own or purchase it first. Add the exact owned domain in **Settings → Pages → Custom domain**, verify it in GitHub account settings, and only then configure DNS in your registrar. The GitHub Actions workflow does not need a `CNAME` file. Never configure domain DNS to a GitHub Pages site before claiming and verifying it.
- Sources: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site and https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/verifying-your-custom-domain-for-github-pages .
- The portfolio is not guaranteed to contain every published mention of the name, and automated news/works are explicitly **unreviewed discoveries**.
- To test locally run `python scripts/build_site.py` from the project root, then run `python -m http.server 8000 -d _site` and open `http://localhost:8000`.
